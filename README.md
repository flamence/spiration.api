## Quick Start

Recommend configuring this project with CMake:

```cmake
FetchContent_Declare(
    spiration.api
    GIT_REPOSITORY https://github.com/flamence/spiration.api.git
    GIT_TAG 0.1.0 # Use a stable version.
)
FetchContent_MakeAvailable(spiration.api)
```

Learning more on [Spiration Documents](https://flamence.github.io/spiration.docs/en/).
